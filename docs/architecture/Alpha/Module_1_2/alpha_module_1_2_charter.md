# Project Context

Alpha Module 1–2 is the first applied financial-domain stage in the Fanisi Digital stack.

It consumes validated outputs from Tutor 1, Tutor 2, and Tutor 3 Phase 1, then performs financial interpretation, diagnostic analysis, and metric definition work on the cleaned Fanisi Digital dataset.

This module is responsible for turning validated operational data into financial truth structures that can later support executive reporting.

---

# Mission

Run the applied financial diagnostics required to establish trustworthy revenue and margin interpretation for Fanisi Digital.

Alpha Module 1–2 exists to:

- test statement reliability
- detect compliance-cost understatement
- determine correct net revenue treatment for USD-invoiced international clients
- build a segmented P&L by commercial model
- run variance analysis with root cause classification
- write metric definition entries for all validated findings

# Non-Goals

Alpha Module 1–2 shall not:

- redesign the upstream schema
- redefine business entity ownership
- change grain or relationship structure
- build dashboards
- create BI visuals
- produce presentation polish
- invent unsupported financial assumptions
- silently resolve contradictions in source data
- substitute estimates where evidence is available

---

# Deliverables

Alpha Module 1–2 shall produce:

- Four-Point Statement Reliability Diagnostic
- Compliance-Cost Understatement Assessment
- Net Revenue Treatment Memo for USD-Invoiced International Clients
- Segmented P&L
- Gross Margin by Segment
- Variance Analysis
- Price / Volume Decomposition
- Controllable vs Non-Controllable Cost Classification
- Root Cause Notes
- Metric Definition Entries
- Alpha Domain Layer Handoff

---

# Exit Criteria

Alpha Module 1–2 is complete only when all of the following are true:

- statement reliability has been tested using the defined four-point diagnostic
- compliance-cost understatement has been assessed and documented
- USD invoice treatment has been classified and justified
- segmented P&L is complete for fixed-price projects versus retainers
- gross margin has been computed per segment
- variance analysis is complete
- root causes are documented
- metric definitions are written in the established documentation format
- all findings are traceable to validated upstream inputs
- unresolved contradictions are explicitly logged
- the Alpha Domain Layer handoff is complete
